# Changelog

Significant changes to AI Bharatiyaa Commons are recorded here. The project
uses semantic versioning while it is pre-1.0: minor releases may expand the
contract, and breaking token changes require a migration note.

## Unreleased

### Added

- Adoption-ready v0.2 documentation and quality gates.
- Semantic tokens for interaction, form, layout, icon, and layering roles.
- Reference patterns for forms, system feedback, AI provenance, responsive
  layout, density, and application accents.
- A dependency-free validator for token references and critical contrast pairs.

### Changed

- The living preview now describes the v0.2 contract rather than only the v0.1
  foundation.

## 0.1.0 - 2026-10-11

### Added

- Initial UI standards and CSS design tokens.
- Living visual preview for identity, a developer tool, and system states.
- Incremental adoption and commons-promotion rules.
